# Fenz Audio Clipper downloads

Official public release downloads for **Fenz Audio Clipper**, a Windows 11 instant audio capture, clip editor and soundboard application with an optional Elgato Stream Deck plugin.

**Website:** https://fenzapps.co.uk/audio-clipper.html

**Downloads:** https://fenzapps.co.uk/audio-clipper-downloads.html

This repository is for compiled public installers and release notes only. Application source code is maintained privately.

## Installing

1. Download `FenzAudioClipper-Setup.exe` from the latest release and install it on Windows 11.
2. Optionally download `streamdeck-plugin.zip` from the same release and follow the [setup guide](https://fenzapps.co.uk/audio-clipper-guide.html).
3. For support, email contact@fenzapps.co.uk.

**Licensing:** Current release is free. Any future paid features will be announced separately.
